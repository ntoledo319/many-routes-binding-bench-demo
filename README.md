# Binding Bench free input playground

An original, MIT-licensed two-key remapping example running on Godot 4.5.1. Keyboard bindings, fixed controller movement, dead-zone and enable controls. Settings stay in memory. Free source ZIP included. No paid checkout or full persistence/recovery source is hosted here.

This web export includes the Godot engine; see GODOT_LICENSE.txt and GODOT_COPYRIGHT.txt. Desktop keyboard use is intended. Physical controller compatibility is untested.
